# 🌧️ Highland Rainfall & Rice — ฝนบนพื้นที่สูงกับผลผลิตข้าวนาปี 2022–2023

Dashboard ภาษาไทยสำหรับตอบคำถามวิจัยหลัก:

> **ปริมาณน้ำฝนบนพื้นที่สูง (HRDI) หรือปริมาณน้ำฝนระดับจังหวัด (HII) มีความสัมพันธ์กับการเปลี่ยนแปลงของผลผลิตข้าวนาปีมากกว่ากันในช่วงปี 2022–2023?**

เปิดดูได้ที่ https://kanokwan-hongsopa.github.io/Highland_Rainfall_Project/ (ไฟล์ `docs/index.html`) หรือรันด้วย Streamlit (`app.py`)

**คำตอบปัจจุบัน: ยังไม่สามารถสรุปได้** — บน 26 ตำบลชุดเดียวกัน ฝน พ.ค.–ส.ค. ค่าต้นทาง ρ(HRDI) = −0.08 และ ρ(HII) = −0.01 ผลต่าง −0.07 (95% CI −0.61 ถึง +0.48) ช่วงความเชื่อมั่นทุกค่าคร่อม 0 ทั้งแบบสุ่มรายตำบลและแบบสุ่มทั้งจังหวัด และผลไม่เปลี่ยนเมื่อใช้ฝนทั้งปี (รวมค่าประมาณ) หรือตัดตำบลที่สถานีอยู่นอกเขต > 5 กม.

## 🧪 วิธีวิเคราะห์

**ผลหลัก (แท็บ 4)**
- กลุ่มตัวอย่าง: 26 ตำบลใน 6 จังหวัดที่มีทั้งสถานี HRDI ฝน HII และผลผลิตครบ 2 ปี (เชียงใหม่ 14 ตำบล) — แยกจากข้าวทั้งหมด 921 ตำบล
- ช่วงฝน: พ.ค.–ส.ค. ค่าต้นทางเท่านั้น (ไม่ใช้ค่าประมาณ) ใช้ช่วงเดียวกันทั้ง HRDI และ HII
- ตัวแปร: การเปลี่ยนแปลง 2023 − 2022 ของฝนและผลผลิตต่อไร่ วัดด้วย Spearman ρ
- ความไม่แน่นอน: 95% CI แบบ bootstrap รายตำบล และแบบสุ่มทั้งจังหวัด (cluster bootstrap 6 กลุ่ม เพราะตำบลในจังหวัดเดียวกันไม่อิสระต่อกัน และ HII มีค่าเดียวต่อจังหวัด) • ไม่มีตำบลใดใช้สถานีชุดเดียวกัน
- ข้อสรุปสร้างอัตโนมัติ: ถ้า CI ของผลต่าง ρ(HRDI) − ρ(HII) คร่อม 0 จะแสดง "ยังไม่สามารถสรุปได้" ไม่บังคับให้มีผู้ชนะ
- ทดสอบความไว: ฝน ม.ค.–ธ.ค. (HRDI รวมค่าประมาณ 17%) และตัดตำบลที่สถานีอยู่นอกเขต > 5 กม. (`src/61`)

**ตรวจคุณภาพข้อมูลก่อนคัดออก** (`src/62_rice_yield_qa.py`, ตารางใน `data/analysis_ready/rice_yield_qa_flags.csv`)

| ข้อสงสัย | แถว | หลักฐาน | การใช้งาน |
|---|---|---|---|
| ผลผลิตต่อไร่ = 0 เพราะพื้นที่เก็บเกี่ยว = 0 | 27 | ไฟล์ต้นทาง DOAE มีพื้นที่เก็บเกี่ยว = 0, ผลผลิต = 0 และ `product_avg` ว่าง (บันทึก มิ.ย.–ส.ค.) ค่า 0 เกิดจากการหาร 0/0 ในขั้นประมวลผล | ไม่นับในผลหลัก (S1) • นับใน S0 |
| ผลผลิตต่อไร่ < 50 กก./ไร่ | 14 | คำนวณซ้ำตรงกับต้นทาง — เป็นค่าจากต้นทางเอง (เช่น พิษณุโลก) | นับในผลหลัก • ไม่นับใน S2 |
| ผลผลิตต่อไร่ > 1,200 กก./ไร่ | 5 | คำนวณซ้ำตรงกับต้นทาง | นับในผลหลัก • ไม่นับใน S2 |
| สถานีฝน อุทยานหลวงราชพฤกษ์ | 1 สถานี | เครื่องวัดของ สวพส. บันทึก 0 มม. ทุกเดือน 2021–ก.ค. 2023 ขณะสถานีอื่นในเชียงใหม่ได้ 150–320 มม./เดือน | ไม่นับในค่าเฉลี่ยฝนหลัก (34 → 33 สถานี) |

เกณฑ์ 50 / 1,200 กก./ไร่ เป็นกฎตรวจจับเบื้องต้นที่ผู้วิเคราะห์กำหนด ไม่ใช่เกณฑ์ที่ยืนยันว่าข้อมูลผิด

**ผลผลิตรายจังหวัดและภาพรวม** ใช้ค่าถ่วงน้ำหนักพื้นที่เก็บเกี่ยว (Σผลผลิต ÷ Σพื้นที่เก็บเกี่ยว) ไม่ใช่ค่าเฉลี่ยธรรมดาของตำบล

## 📈 ตัวเลขหลัก (ผ่านการตรวจแล้ว)

- ฝน ม.ค.–ส.ค. (33 สถานีที่มีค่าต้นทางครบทั้งสองปี): HRDI 1,311.9 → 919.0 มม. (−30%) • HII 1,098.9 → 550.6 มม. (−50%)
- ผลผลิตข้าวภาพรวม: ถ่วงน้ำหนักพื้นที่เก็บเกี่ยว 674.4 → 661.6 กก./ไร่ (−1.9%) แต่ค่าเฉลี่ยธรรมดา 643.7 → 648.2 (+0.7%) — **ทิศทางขึ้นกับวิธีคำนวณ จึงยังไม่สามารถสรุปทิศทางการเปลี่ยนแปลงของผลผลิตรวมได้**

## ⚠️ ข้อจำกัด

1. ข้อมูล 2 ปี จึงมีการเปลี่ยนแปลง 1 ครั้งต่อตำบล • ผลเป็นเชิงสำรวจ ไม่ใช่เหตุและผล และไม่มีการพยากรณ์
2. ฝน HRDI ของชุด 26 ตำบล ช่วง พ.ค.–ส.ค. มาจาก OpenWeatherMap 230 จาก 232 แถว — วิเคราะห์เฉพาะเครื่องวัดจริงไม่ได้
3. ไม่มีฝนต้นทาง HRDI ก.ย.–ธ.ค. 2023 (ช่วงออกรวง) • HII มีค่าเดียวต่อจังหวัด (6 ค่าใน 26 ตำบล)
4. ยังแยกไม่ได้ว่าแถวที่ไม่มีพื้นที่เก็บเกี่ยวคือ "ยังไม่เก็บเกี่ยว" หรือ "เสียหายทั้งหมด" • ค่าที่ต้องตรวจสอบควรยืนยันกับ DOAE
5. ไม่ทราบตำแหน่งแปลงนาในตำบล • 3 คู่สถานี–ตำบลอยู่นอกเขตเกิน 5 กม.
6. ความเร็วลมปี 2023 สูงกว่าปี 2022 ราว 3.8 เท่าในแหล่งเดียวกัน (ไม่ได้ใช้ในการวิเคราะห์)
