# DATA DICTIONARY

ขอบเขตข้อมูลวิเคราะห์ข้าวนาปี: 2022–2023 (ช่วงวิเคราะห์หลัก: พฤษภาคม–สิงหาคม)

เอกสารนี้สร้างจากไฟล์ Dashboard ที่ผ่านการตรวจโครงสร้าง
โดยคำอธิบายหน่วยวัดที่ยังไม่ยืนยันถือเป็นข้อจำกัดสำคัญตามหลักธรรมาภิบาลข้อมูล

## dashboard_rice_tambon.csv

ข้อมูลผลผลิตข้าวนาปีและฝนระดับตำบล-ปี

- จำนวนแถว: 50 (25 ตำบล × 2 ปี Balanced Panel)
- ขอบเขตพื้นที่: 5 จังหวัด (เชียงใหม่ 14, น่าน 5, แม่ฮ่องสอน 3, ตาก 2, เชียงราย 1)
- การจับคู่เชิงพื้นที่: จับคู่สถานี 28 แห่งกับ 25 ตำบลตามชื่อเขตการปกครอง (Administrative Name-Based Matching) ไม่ใช่การตรวจพิกัด GPS ในแปลงนาจริง
- คอลัมน์:

  - `year`: ปี ค.ศ. (2022, 2023)
  - `province_id`: รหัสจังหวัด 2 หลัก
  - `tambon_code_6`: รหัสตำบล 6 หลัก
  - `rice_yield_per_harvest_area`: ผลผลิตรวม / พื้นที่เก็บเกี่ยวรวม; หน่วยรอยืนยันตามข้อกำหนด BRD
  - `hrdi_may_aug`: ผลรวมฝน HRDI พฤษภาคม–สิงหาคม (ช่วงวิเคราะห์หลัก: ต้นฤดูปลูก/ระยะแตกกอ); หน่วยรอยืนยัน
  - `hii_may_aug`: ผลรวมค่า AvgRain ของ HII พฤษภาคม–สิงหาคม (ช่วงวิเคราะห์หลัก); นิยามและหน่วยรอยืนยัน
  - `hrdi_feb_jul`: ผลรวมฝน HRDI กุมภาพันธ์–กรกฎาคม (คงไว้สำหรับ Sensitivity Comparison); หน่วยรอยืนยัน
  - `hii_feb_jul`: ผลรวมค่า AvgRain ของ HII กุมภาพันธ์–กรกฎาคม (คงไว้สำหรับ Sensitivity Comparison); นิยามและหน่วยรอยืนยัน
  - `station_count`: จำนวนสถานี HRDI ที่ใช้ประกอบข้อมูลตำบล (1 หรือ 2 สถานี)

## dashboard_province_changes.csv

การเปลี่ยนแปลงระดับจังหวัดระหว่าง 2022–2023 (2023 ลบ 2022)

- จำนวนแถว: 5
- คอลัมน์:

  - `province_id`: รหัสจังหวัด 2 หลัก
  - `tambons`: จำนวนตำบลที่ใช้วิเคราะห์ในจังหวัดนั้น
  - `mean_yield_change`: ค่าเฉลี่ยการเปลี่ยนแปลงผลผลิตต่อพื้นที่ (2023 ลบ 2022) ระดับจังหวัด
  - `mean_hrdi_change`: ค่าเฉลี่ยการเปลี่ยนแปลงฝน HRDI พ.ค.–ส.ค. (2023 ลบ 2022) ระดับจังหวัด
  - `hii_change`: การเปลี่ยนแปลงฝน HII พ.ค.–ส.ค. (2023 ลบ 2022)
  - `mean_hrdi_feb_jul_change`: ค่าเฉลี่ยการเปลี่ยนแปลงฝน HRDI ก.พ.–ก.ค. (คงไว้เทียบเคียง)
  - `hii_feb_jul_change`: การเปลี่ยนแปลงฝน HII ก.พ.–ก.ค. (คงไว้เทียบเคียง)

## dashboard_correlations.csv

ผลความสัมพันธ์ Spearman เชิงสำรวจ (ช่วงวิเคราะห์หลัก: พ.ค.–ส.ค.)

- จำนวนแถว: 3
- คอลัมน์:

  - `analysis`: ชื่อระดับการวิเคราะห์ (HRDI_tambon, HRDI_province, HII_province)
  - `n`: จำนวนหน่วยวิเคราะห์ (25, 5, 5)
  - `spearman_rho`: ค่าสหสัมพันธ์อันดับ Spearman (-0.0270, -0.7000, +0.1000)
  - `analysis_type`: ประเภทการวิเคราะห์ (exploratory)
  - `causal_interpretation_allowed`: False (ห้ามสรุปว่าฝนเป็นสาเหตุของการเพิ่มหรือลดผลผลิต และห้ามอ้างว่าปัจจัยอื่นมีอิทธิพลมากกว่าฝนโดยไม่มีการวิเคราะห์รองรับ)
  - `rain_window`: ช่วงเดือนที่ใช้รวมค่าฝน (May-Aug)
  - `crop_season_verified`: ระยะการเจริญเติบโตทางลำต้น (Vegetative Stage: ต้นฤดูปลูกถึงแตกกอ ไม่ใช่ฤดูปลูกเต็มฤดู)
  - `source_units_verified`: False (ยังไม่ได้รับการยืนยันทางการจากหน่วยงานต้นทาง)
