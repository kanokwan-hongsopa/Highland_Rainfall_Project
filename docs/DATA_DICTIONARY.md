# DATA DICTIONARY

ขอบเขตข้อมูลวิเคราะห์ข้าวนาปี: 2022–2023

เอกสารนี้สร้างจากไฟล์ Dashboard ที่ผ่านการตรวจโครงสร้าง
โดยคำอธิบายหน่วยวัดที่ยังไม่ยืนยันถือเป็นข้อจำกัด

## dashboard_rice_tambon.csv

ข้อมูลผลผลิตข้าวนาปีและฝนระดับตำบล-ปี

- จำนวนแถว: 50
- คอลัมน์:

  - `year`: ปี ค.ศ.
  - `province_id`: รหัสจังหวัด 2 หลัก
  - `tambon_code_6`: รหัสตำบล 6 หลัก
  - `rice_yield_per_harvest_area`: ผลผลิตรวม / พื้นที่เก็บเกี่ยวรวม; หน่วยรอยืนยัน
  - `hrdi_feb_jul`: ผลรวมฝน HRDI กุมภาพันธ์–กรกฎาคม; หน่วยรอยืนยัน
  - `hii_feb_jul`: ผลรวมค่า AvgRain ของ HII กุมภาพันธ์–กรกฎาคม; นิยามและหน่วยรอยืนยัน
  - `station_count`: จำนวนสถานี HRDI ที่ใช้ประกอบข้อมูลตำบล

## dashboard_province_changes.csv

การเปลี่ยนแปลงระดับจังหวัดระหว่าง 2022–2023

- จำนวนแถว: 5
- คอลัมน์:

  - `province_id`: รหัสจังหวัด 2 หลัก
  - `tambons`: จำนวนตำบลที่ใช้วิเคราะห์
  - `mean_yield_change`: ค่าเฉลี่ยการเปลี่ยนแปลงผลผลิตต่อพื้นที่ (2023 ลบ 2022) ระดับจังหวัด
  - `mean_hrdi_change`: ค่าเฉลี่ยการเปลี่ยนแปลงฝน HRDI (2023 ลบ 2022) ระดับจังหวัด
  - `hii_change`: การเปลี่ยนแปลงฝน HII (2023 ลบ 2022)

## dashboard_correlations.csv

ผลความสัมพันธ์ Spearman เชิงสำรวจ

- จำนวนแถว: 3
- คอลัมน์:

  - `analysis`: ชื่อระดับการวิเคราะห์
  - `n`: จำนวนหน่วยวิเคราะห์
  - `spearman_rho`: ค่าสหสัมพันธ์อันดับ Spearman
  - `analysis_type`: ประเภทการวิเคราะห์
  - `causal_interpretation_allowed`: อนุญาตให้ตีความเชิงเหตุและผลหรือไม่
  - `rain_window`: ช่วงเดือนที่ใช้รวมค่าฝน
  - `crop_season_verified`: ยืนยันความตรงกับฤดูปลูกแล้วหรือไม่
  - `source_units_verified`: ยืนยันนิยามและหน่วยวัดต้นทางแล้วหรือไม่
